# 디자인 문서 (Designer)

> 이 문서는 **어떻게 보이고 느껴져야 하는가**를 기록합니다. 값의 원본은 `style.css`의 `:root`입니다.
> 마지막 갱신: 2026-11-23

## 1. 무드
따뜻한 도시락 · 손그림 느낌. **두꺼운 갈색 외곽선(2~2.5px) + 아래로 떨어지는 단단한 그림자**, 크림색 배경, 둥근 모서리. 귀엽지만 정보는 또렷하게.

## 2. 색상 (디자인 토큰)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--cream` | `#FFF8E7` | 페이지 배경, 필터 패널 |
| `--ink` | `#3A2E1F` | 외곽선, 기본 글자 |
| `--ink-deep` | `#2A1E12` | 제목·강조 글자 |
| `--muted` | `#6B5A43` | 보조 글자 (13px 안팎) |
| `--yellow` | `#FFD45C` | 기본 핀, 주요 강조 |
| `--butter` | `#FFE8A3` | 연한 노랑 면 |
| `--mint` / `--mint-soft` | `#8FD9C9` / `#CFEFE7` | 지도·카드 배경, 보조 면 |
| `--coral` / `--coral-soft` | `#FF8A7A` / `#FFE0DA` | 선택 핀, 점, 포인트 |
| `--red-num` | `#C4422F` | 순위 % 숫자 |
| `--line` | `#D9C9A8` | 구분선·점선 |

규칙: 새 색을 쓰기 전에 위 토큰으로 해결되는지 먼저 본다. 새 색이 필요하면 `:root`에 토큰으로 추가하고 이 표도 고친다.

## 3. 타이포
| 용도 | 글꼴 | 비고 |
|---|---|---|
| 로고, 헤드라인, 화면 제목(`.logo span`, `.headline`, `.screen-title`) | **Jua(주아체)** | 이 세 곳에만 사용 |
| 그 외 모든 본문·버튼·지도 | **Pretendard Variable** | 폴백: Apple SD Gothic Neo, Malgun Gothic |
- 본문 15px / 줄간격 1.5, 보조글 13px, 헤드라인 28px, 로고 24px, 말풍선 13px(굵게).
- 굵기: 제목류 700, 일반 400.

## 4. 레이아웃
- **모바일 우선.** 콘텐츠 폭 최대 480px 중앙 정렬, 좌우 패딩 20px.
- **데스크톱 (≥ 900px)**: 왼쪽 480px 고정 홈 열 + 오른쪽 전체 **지도 고정(fixed)**. 맛집 카드는 지도 위 오른쪽 **떠 있는 패널**(폭 400px, 모서리 30px).
- 홈 구성: 로고 → 헤드라인 → 바로가기 버튼 → 지도(모바일 260px 높이, "지도 크게 보기" 버튼) → 목록.
- 바로가기: 2×2 그리드(맛집 탐색·제비뽑기·TOP30·동네 인기). 열려 있는 메뉴는 눌린 모양(`aria-pressed`)으로 표시. 큰 카드형 버튼 + 아이콘 + 두 줄 문구(굵은 제목 / 작은 설명).
- 메뉴 화면(`.screen`): 홈의 목록 자리에 인라인으로 표시. 닫기 아이콘 → 제목 → 필터 → 결과. 지도는 그대로 유지.

## 5. 컴포넌트
| 컴포넌트 | 클래스 | 특징 |
|---|---|---|
| 바로가기 | `.sc` | 색 카드(노랑/민트/코랄 계열) + 외곽선 + 그림자 |
| 칩 | `.chips`, `.chip` | 선택 시 채움. 작은 버전 `.small` |
| 지역 선택 | `.regions` | 이름 + 부제(예: 국회·KBS 쪽) |
| 목록 항목 | `renderList` | 순위 원형 숫자 + 가게명 + 태그 + 오른쪽 "지역 상위 x%"(`--red-num`) |
| 맛집 카드 | `.pane` | 상단 도시락 뚜껑(코랄색 띠, 캐릭터 없음) + 큰 숫자 두 개(전국/지역) + 점선 정보표 + 주요 버튼(노랑) |
| 지도 컨테이너 | `.map-wrap`, `.map-slot` | 외곽선 2.5px, 모서리 24px, 그림자 |
| 아이콘 | 인라인 SVG, 24px 격자, 외곽선형 | 선 굵기 일정 |

## 6. 지도 핀 (가장 손이 많이 가는 곳)
- **번호 핀 `.pin`**: 30×30 네모를 -45° 회전해 물방울 모양. 노랑 배경 + 외곽선 + 아래 그림자. 숫자는 `i`를 +45° 돌려 똑바로 보이게 한다. 대상: 순위 1~10위.
- **선택 핀 `.pin.sel`**: 코랄색, 36×36, 숫자 16px. 선택한 매장은 항상 맨 위(z-index 최상).
- **점 `.dot`**: 12px 코랄 원 + 2px 외곽선. 11위 이하.
- **말풍선 `.nm-tip`**: 흰 배경 + 2px 외곽선 + 둥근 10px, 굵은 13px. "순위. 가게명".
- ⚠ **핀의 크기·모양·테두리를 바꾸면 `app.js` `addPin`의 앵커 계산(`tipY`)도 반드시 같이 수정.** 핀 끝이 실제 좌표에 닿는 위치가 달라져 핀이 어긋나 보인다.
- 지도 바탕은 카카오맵 기본 스타일. 앱 팔레트와 어울리도록 핀 색 대비를 유지한다.

## 7. 모션 · 접근성
- 지도 이동은 **한 번의 부드러운 이동**으로(튕기거나 점프하지 않게). 상세는 `development.md` 5번.
- `prefers-reduced-motion`이면 모든 애니메이션/전환 제거(이미 `style.css`에 반영).
- 터치 대상 최소 40px(지도 크게 보기의 닫기는 48px). 아이콘 버튼엔 `aria-label` 필수.
- 화면은 `role="dialog"` + `aria-labelledby`, 칩 그룹은 `role="group"` + 라벨 연결.
- 글자 대비: 본문 `--ink` on `--cream`. 연한 `--muted`는 13px 이상 보조 정보에만.

## 8. 문구 톤 (보이스)
- 반말에 가까운 친근한 존댓말, 짧게. 예: "의도리가 몰래 봤어요", "도시락 뚜껑 열기", "핀으로 한눈에".
- 지도 오류: "지도를 불러오지 못했어요. 카카오 JavaScript 키와 등록한 웹 도메인을 확인해 주세요."
- 영업 시간은 항상 "예상"을 붙여 공식 정보가 아님을 알린다.
- 이름 규칙: 캐릭터 **의도리**(과거 "도락이"로 바꿨다가 되돌림), 서비스명 **여의도시락**.

## 8-1. 캐릭터 "의도리"
- 컨셉: **노란 도시락 통이 몸**인 캐릭터. 앞면에 웃는 얼굴과 작은 다리가 있고, 안에는 국회의사당 돔을 얹은 밥(얼굴 있음), 브로콜리, 시금치, 방울토마토, 계란말이, 63빌딩(얼굴 있음)이 들어 있다.
- 원본은 사용자가 준 일러스트 한 장(좌·우 두 캐릭터, 글씨 제외). 좌우로 잘라 흰 배경을 투명하게 만든 PNG로 쓴다.
  - **왼쪽(숟가락·젓가락을 든 의도리) = 표지/메인** → `dori.png`. 홈 헤더에서 로고 글자 오른쪽 빈 공간에 크게(`.top-dori`, 최대 180px). 파비콘도 이 그림.
  - **오른쪽(제비 컵과 제비 쪽지를 든 의도리) = 제비뽑기** → `dori-pick.png`. 제비뽑기 장면(`#cup`)에서 사용.
- 제비뽑기 동작: 평소엔 컵에 꽂힌 제비만 보인다. "젓가락 뽑기!"를 누르면 장면이 흔들린 뒤(`.shake`) 컵 입구에서 **빨간 제비 하나가 솟아오른다**(`.lucky`, 입구 위쪽만 보이게 `clip-path`로 자름). 컵 위치나 이미지 크기를 바꾸면 `#cup` SVG의 `cup-mouth` 클립(y=192)과 `.lucky` 좌표도 같이 고친다.
- 맛집 카드 상단의 도시락 뚜껑에는 캐릭터를 넣지 않는다.
- 이미지를 바꾸면 `dori.png`, `dori-pick.png`, `favicon.svg`를 같이 다시 만든다.

## 10. 유지보수 규칙
- 색·글꼴·크기를 바꾸면 이 문서 2·3번 표와 `style.css`를 **같이** 고친다.
- 새 컴포넌트를 만들면 5번 표에 한 줄 추가한다.
