# 기획 문서 (Planner)

> 이 문서는 **무엇을, 왜 만드는가**를 기록합니다. 기능이 바뀌면 이 문서부터 고치세요.
> 마지막 갱신: 2026-11-23 · 담당: bora

## 1. 서비스 한 줄
**여의도시락** — "광고 말고 영수증이 고른 집". 별점이 아니라 여의도 직장인들이 실제로 많이 결제한 순서로 맛집을 보여 주는 모바일 우선 웹 서비스.

- 캐릭터: **의도리**(도시락 캐릭터). 홈 로고와 카드 상단에 등장.
- 주소: https://yeouidosirak.vercel.app
- 성격: BC카드·잇플(eat.pl) 공식 서비스 아님 (공모전 출품용, README의 데이터 고지 참고)

## 2. 타깃과 쓰임새
| 누가 | 언제 | 원하는 것 |
|---|---|---|
| 여의도 직장인 | 점심·회식·야근 전 | "오늘 어디 가지?"를 빠르게 결정 |
| 방문객 | 주말·행사 | 광고 아닌 실제 인기 집 |

핵심 동선: **고른다 → 카드를 연다 → 잇플로 이동(메뉴·후기·영업 확인)**. 잇플 링크가 이 서비스의 핵심 전환 지점이다.

## 3. 기능 목록 (현재 상태)
| 기능 | 화면 id | 상태 | 설명 |
|---|---|---|---|
| 홈 목록 | 홈 | 완료 | 전체 858곳을 지역 매출 상위 순으로 표시 |
| 맛집 탐색 | `explore` | 완료 | 지역·종류·분위기·고객층 조건으로 찾기 |
| 지도에서 보기 | `map` | 완료 | 카카오맵 + 번호 핀. 필터와 연동 |
| 제비뽑기 | `pick` | 완료 | 조건(기본: 밥집·점심·상위 30)에 맞는 집을 젓가락으로 뽑기 |
| TOP30 | `top30` | 완료 | 가장 많이 결제된 집 |
| 동네 인기 | `local` | 완료 | 동네 사람이 많이 가는 집 |
| 맛집 카드 | 우측 패널 / 모바일 전체 | 완료 | 순위·영업 예상 시간·주요 손님·공유·카카오맵 길찾기 |
| 공유 | 카드 | 완료 | `?p=<id>` 링크로 단톡방 공유 |

## 4. 필터 용어 (사용자에게 보이는 말)
- **지역**: 전체 / 서여의도(국회·KBS 쪽) / 더현대·IFC(파크원 포함) / 동여의도(증권가·63 쪽)
- **종류**: 전부 / 밥집 / 카페·디저트 / 술집
- **분위기**: 점심 / 회식 / 늦게까지 / 외국인 많은 / 동네 사람 맛집
- **고객층**: 2030·4050·60대 이상 × 여성/남성 (6개)
- **순위 표기**: "전국 매출 상위 x%", "지역 매출 상위 x%" (낮을수록 상위)

## 5. 데이터 정책
- 출처: 잇플(BC카드 결제 데이터), 최근 1개월 기준. 영업 시간은 **첫·마지막 결제 시각 기반 추정**(공식 영업시간 아님, 30분 단위 반올림).
- 제외 대상: 편의점·마트·소매·반찬·매점, 위탁급식·구내식당 운영사, 알아볼 수 없는 법인명.
- 가게 이름은 법인 표기를 정리해 사람이 아는 이름으로 보여 준다 (`cleanName`).
